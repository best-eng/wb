Основные CSS свойства

Первый абзац страницы. Он покрашен в зелёный цвет атрибутом style, хотя в CSS-файле всем абзацам задан красный. Атрибут style стоит ближе к элементу, поэтому побеждает он.

Второй абзац страницы. Он покрашен в красный цвет атрибутом style. Для него же отдельно убрана красная строка и задано выравнивание по центру — в CSS это сделано через псевдокласс nth-of-type(2).

Заголовок второго уровня

Обычный абзац. К нему применяются все правила из файла styles.css: цвет, ширина, выравнивание по ширине, курсив, размер и гарнитура шрифта, межстрочный интервал и красная строка.

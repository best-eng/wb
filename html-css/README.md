# Практические работы по HTML и CSS

Пять практических работ из методички. Каждая работа — отдельная папка,
каждое задание — отдельный файл. Открывается двойным щелчком в браузере,
ничего устанавливать не нужно. Общее оглавление со ссылками — `index.html`.

## Что где лежит

| Файл | Задание |

| `pr1/paragraph.htm` | Заголовки `H1`/`H2`, абзацы `P`, линейка `HR`, фраза «Нас утро встречает прохладой» по образцу, подпись автора через `FONT SIZE="+2"` и `I` |
| `pr1/paragraph_2.htm` | Монолог Гамлета: выравнивание по центру, по ширине, абзац между двумя `HR`, разбиение на абзацы |

## Пояснения к решениям

**Кодировка.** В каждый документ добавлена строка `<meta charset="utf-8">`.
В методичке её нет, но без неё браузер угадывает кодировку сам и кириллица
может превратиться в «кракозябры». Файлы сохранены в UTF-8.

**Работа №2, задание 13.** Четыре таблички отличаются только тем, какие
ячейки объединены: `colspan` объединяет по горизонтали, `rowspan` — по
вертикали. Таблички вложены в одну таблицу-обёртку, чтобы стояли в ряд,
как на рисунке.

**Работа №3, «исправьте ошибки».** Найдено семь ошибок, они перечислены
прямо на странице `form_fix.htm` под формой. Главная из них не опечатка:
длинная и короткая сессия исключают друг друга, поэтому там нужны не
флажки, а радио-кнопки с одинаковым `name`.

**Работа №4.** Картинки нарисованы для этих работ и лежат в `pr4/img/`:
`sea.png` — фон документа, `table-bg.png` — фон второй части таблицы,
`email.png` — изображение для кнопок. Основная таблица собрана из двух
частей: первая — «шапка» с объединёнными ячейками, вторая оформлена
дополнительными атрибутами (`background`, `bgcolor`, `frame`, `rules`,
`cellpadding`, `bordercolor`). Надписи над таблицей и под ней сделаны
элементом `CAPTION` с `align="top"` и `align="bottom"`.

**Работа №5, `pr5/zadaniya/styles.css`.** Блоки идут в том же порядке,
что и задания. Два момента:

- В блоке «На свойство-сокращение font» по заданию закомментированы все
  предыдущие стили шрифта для абзацев — они остались в файле в виде
  комментариев, чтобы было видно, что именно заменило свойство `font`.
- Свойство `font` сбрасывает `font-style`, поэтому правило «первый абзац
  не курсивом» повторено после него — иначе оно перестало бы работать.

**Работа №5, макеты.** HTML и CSS повторяют образцы из методички.
Картинки в `pr5/maket2/images/` — свои (по заданию «картинки и текст
можно любой»).

Все страницы открыты в браузере Chromium и сверены с образцами из
методички: скриншоты лежат в `_screenshots/`.
